# Ghost Screener — revenue plan (later; nothing implemented in v1)

1. **Paid "Featured" slots, paid in SOL, verified on-chain.** Fixed price per slot per 24h/7d. Buyer sends SOL to a dedicated project wallet with a unique memo/reference key (Solana Pay "reference"); a small serverless worker (Cloudflare Worker / Vercel function) watches the wallet over an RPC (Helius/QuickNode free tier), confirms amount + reference, and writes the slot to a JSON file the static site reads. Needs: a dedicated receiving wallet (not the creator-fee wallets), a backend + RPC key, a manual review/refusal policy (no obvious scams/impersonators), a refund policy, clear "Paid placement" labels, and an accounting/tax check by Chef.
2. **Jupiter swap widget with a platform fee.** Embed Jupiter Terminal/Plugin on the token page; Jupiter lets integrators set a platform fee (in bps) paid to a referral/fee account. Needs: a Jupiter referral account + fee token accounts set up from a wallet Chef controls, disclosure of the fee in the UI, and a legal look at whether operating a swap front-end with fees triggers any regulation where Chef lives. Revenue is volume-dependent and small until traffic exists.
3. **Sponsored "Boost" upgrades on top of a listing** (e.g. pinned row in Trending for N hours, highlighted row). Same on-chain payment flow as #1; strictly time-boxed and labeled "Boosted (paid)". Needs: the same backend, plus rules so paid boosts never change displayed numbers or imply quality.
4. **Simple display/sponsor banner** sold directly via X DMs (@GrokBotreal) at a flat weekly rate before any automation exists. Needs: nothing technical beyond swapping an image/link; requires manual invoicing and vetting. Good way to test demand before building #1.
5. **Prerequisite for all of the above: data licensing.** DexScreener's API terms forbid using the API for a product whose primary purpose is to compete directly with DexScreener; a monetized screener could be read that way. Before charging money, either rely only on sources whose terms allow it (e.g. a paid CoinGecko/GeckoTerminal on-chain API plan, or our own RPC/indexer) or get written OK. Also expect real traffic to require a paid API tier (free GeckoTerminal is ~10–30 calls/min per IP).
